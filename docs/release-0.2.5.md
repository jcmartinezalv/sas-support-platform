# SAS 0.2.5

Fecha: 2026-07-15

## Instalacion separada

- Setup completo reservado para el equipo principal SAS.
- Nuevo SAS Cliente Setup para computadoras de usuarios.
- Liga temporal de un solo uso asociada al ticket.
- Boton Enviar liga de instalacion dentro de la conversacion WhatsApp.
- Pagina publica con descarga, codigo temporal, instrucciones y advertencias.
- Credencial individual por equipo; el secreto general no se entrega al cliente.
- Vinculacion automatica y aviso de Fisher cuando termina la instalacion.
- Instalacion no concede consentimiento remoto, vista ni control.
- Perfil restringido mientras los binarios no tengan firma comercial.

## Validacion

- 180 pruebas automaticas aprobadas.
- Flujo de enrolamiento de un solo uso validado extremo a extremo.
