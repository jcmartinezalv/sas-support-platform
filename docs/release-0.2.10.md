# SAS 0.2.10

Fecha: 2026-07-15

## Correccion

- La contrasena escrita en Restablecer ya no desaparece con la actualizacion automatica.
- El refresco se pausa solamente mientras existe una captura pendiente visible.
- Una actualizacion manual conserva el texto, foco y posicion del cursor.
- Despues de enviar correctamente, el campo se limpia y se confirma la revocacion de sesiones.
