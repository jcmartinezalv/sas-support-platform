# SAS 0.2.20

- Renueva preventivamente la sesión web un minuto antes del vencimiento del acceso.
- Evita cierres aparentes durante pruebas prolongadas de soporte.
- Explica que cada pestaña del navegador mantiene una sesión independiente.
- Muestra una alerta de seguridad si se pierde el acceso mientras puede existir soporte remoto.
- Al pulsar **Salir**, advierte y cierra las sesiones remotas abiertas por ese operador antes de invalidar su acceso.
- Audita cada cierre remoto provocado por la salida de la consola.
- Mantiene siempre disponible el paro local del cliente Windows.
- Incluye Android alineado con la versión 0.2.20.
