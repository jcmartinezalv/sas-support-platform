# SAS 0.2.9

Fecha: 2026-07-15

## Cambio principal

La consola web ahora usa las mismas cuentas autorizadas de la aplicacion Android.

- Inicio de sesion con usuario y contrasena.
- Rol obtenido del servidor; ya no se elige manualmente.
- Renovacion automatica y rotacion de tokens.
- Cierre de sesion con revocacion inmediata.
- Cambio obligatorio de contrasena temporal.
- Bloqueo y revocacion compartidos con Android.
- Token maestro disponible solo como recuperacion local.
- Auditoria separada para accesos web.
- Interfaz oscura de alto contraste y ayudas claras.

## Compatibilidad

El instalador conserva configuracion, datos, certificados y credenciales existentes. No es necesario volver a crear los usuarios moviles.
